Materi Praktikum Tersedia (1)

Hukum Pascal (Mesin Hidrolik Pencuci Mobil)

Simulasi interaktif hubungan Gaya Input (F₁), Luas Penampang Kecil (A₁), Luas Penampang Besar (A₂), dan Gaya Angkat Output (F₂) pada fluida dalam ruang tertutup.

P₁ = P₂
F₁ / A₁ = F₂ / A₂
F₂ = (F₁ / A₁) × A₂

Kontrol Variabel Simulasi Hukum Pascal

Gaya Input Piston Kecil (F₁) 200 N
Luas Penampang Kecil (A₁) 0.02 m²
Massa Beban Mobil (m) 800 kg (W = 8.000 N)
Luas Penampang Besar (A₂) 0.40 m²
Tekanan Fluida (P = F₁/A₁): 10.000 Pa
Gaya Angkat Output (F₂): 4.000 N

✗ Belum Terangkat: F₂ (4.000 N) < Berat Mobil (8.000 N)

Visualisasi Interaktif Mesin Hidrolik Pencuci Mobil

Geser tuas F₁, A₁, A₂, atau massa mobil di samping kiri untuk melihat perubahan gaya angkat secara langsung.
